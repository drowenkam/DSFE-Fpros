RECOMMENDED METHOD: GITHUB DESKTOP ON WINDOWS OR MAC
---------------------------------------------------
1. In GitHub Desktop, open or clone https://github.com/drowenkam/FPros
   Select Repository > Show in Explorer (Windows), or Show in Finder (Mac).
2. Make a backup of the folder (recommended).
3. In the *local cloned repository folder*, remove the previous WEBSITE files and
   old website folders (assets/, data/, reference-pdfs/ etc.).
   IMPORTANT: KEEP .git and .github (if present) AND CNAME (if present).
   Do not delete the GitHub repository online or remove its .git folder.
4. Extract THIS ZIP. Copy ALL extracted files and folders into that same local
   FPros repository folder. The file FPros/index.html must exist.
   The file FPros/assets/site.css must exist.
   The file FPros/assets/questions-data.js must exist.
   The file FPros/assets/notebook-index.js must exist.
   NEVER create FPros/FPros/index.html or FPros/assets/assets/...
5. Return to GitHub Desktop. You should see many additions/deletions.
   Commit with the message "Replace FPros site — one notebook and Books I-III".
   Click Push origin and wait for the push to complete.
6. GitHub repository: Settings > Pages: Branch main, /(root), if using branch Pages.
7. After GitHub Pages finishes publishing, open in a PRIVATE/INCOGNITO window:
   https://drowenkam.github.io/FPros/healthcheck.html
   The check should say all required website files are installed.
   Then open https://drowenkam.github.io/FPros/index.html?reset=20261114

FOR MAC: GitHub Desktop > Repository > Show in Finder; the rest is identical.
